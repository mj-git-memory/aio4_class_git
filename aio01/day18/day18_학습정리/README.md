# Day18 소스코드로 배우는 로그인과 나만의 대화 기록

이 자료는 실제 `day18/lesson01`~`lesson08/main.py`, `backend/main.py`, 각 폴더의 `requirements.txt`, `BACKEND_GUIDE.md`, `TODAY_GUIDE.md`를 바탕으로 작성했습니다. 기준일은 2026년 11월 7일입니다.

완성 목표는 **로그인한 사용자가 자신의 대화를 고르고, 문장을 저장하고, 다음 로그인 때 다시 읽을 수 있는 웹 화면**입니다. 현재 코드에는 AI 답변 생성과 회원가입 화면은 없습니다. 계정은 Supabase Auth에 미리 준비합니다.

## 처음에 기억할 세 문장

1. `st.session_state`는 같은 Streamlit 세션에서 화면을 다시 그릴 때 필요한 값을 보관합니다.
2. PostgreSQL은 대화 기록을 오래 저장하고, Redis는 이 앱에서 허용하는 로그인 세션을 일정 시간 보관합니다.
3. 화면에 로그인 표시가 있어도 실제 접근 허용 여부는 백엔드가 매 요청에서 확인합니다.

기존 안내 일부에는 1차시를 포함하지 않는다고 적혀 있지만, 현재 작업 폴더에는 `lesson01/main.py`가 있어 이 문서에서는 함께 설명합니다. 원래 실행 코드는 변경하지 않았으며, 이 문서 작성을 위해 실제 계정 로그인이나 DB 저장을 수행하지 않았습니다.
