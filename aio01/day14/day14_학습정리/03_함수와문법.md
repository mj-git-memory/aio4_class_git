# 주요 함수와 문법 빠르게 보기

아래 예시는 문법을 설명하는 짧은 조각입니다. Redis 예시의 `client`는 `redis.Redis(...)`로 준비한 객체, SQLite 예시의 `conn`은 `sqlite3.connect(...)`로 만든 연결입니다.

## 1. 함수·인자·메서드·반환값

```python
def cache_key(owner):
    return f"lesson05:history:{owner}"

key = cache_key("demo-a")
```

- `def`: 함수 정의. 자주 하는 작업에 이름을 붙입니다.
- `owner`: 함수가 받을 값의 이름인 매개변수
- `"demo-a"`: 호출할 때 전달한 실제 인자
- `return`: 계산한 결과를 호출한 곳에 돌려주기
- `f"...{owner}"`: 문자열 안에 변수의 값을 넣는 f-string

`client.get(key)`처럼 객체 뒤에 점을 붙여 호출하는 함수는 **메서드**입니다. `ex=60`처럼 이름을 붙여 전달하면 **키워드 인자**입니다. `print()`는 화면에 보여주고, `return`은 다른 코드가 사용할 결과를 돌려준다는 차이가 있습니다.

## 2. import와 패키지

```python
import json
from dotenv import load_dotenv
from contextlib import closing
```

`import json`은 `json.dumps()`처럼 모듈 이름을 붙여 사용하고, `from ... import ...`는 필요한 이름을 가져와 `load_dotenv()`처럼 바로 씁니다. 설치 이름 `python-dotenv`와 import 이름 `dotenv`는 다릅니다.

```bash
python -m pip install redis python-dotenv
```

여기서 `-m pip`는 현재 Python 환경의 pip 모듈을 실행하라는 뜻입니다.

## 3. 환경변수와 경로

```python
load_dotenv(".env", override=False, interpolate=False)
host = os.getenv("REDIS_HOST", "")
port = int(os.getenv("REDIS_PORT", ""))
```

| 문법 | 의미 |
|---|---|
| `os.getenv("이름", 기본값)` | 환경변수 읽기. 없으면 기본값 |
| `int("6379")` | 문자열을 정수로 변환. 변환 불가 시 `ValueError` |
| `text.strip()` | 앞뒤 공백을 제거한 새 문자열 반환 |
| `not text.strip()` | 빈 문자열 또는 공백뿐인지 검사 |
| `os.path.isfile(path)` | 해당 경로가 실제 파일인지 확인 |

검사용 `host.strip()`를 호출한다고 원래 `host` 값의 공백이 제거되는 것은 아닙니다. 반환값을 다시 대입해야 실제 변수 내용이 바뀝니다.

```python
from pathlib import Path
env_path = Path(__file__).resolve().parent.parent / ".env"
```

`__file__`은 현재 Python 파일 경로, `resolve()`는 절대 경로로 정리, `.parent`는 상위 폴더입니다. `Path`에서 `/ ".env"`는 나눗셈이 아니라 경로를 연결하는 표현입니다.

인자 없는 `load_dotenv()`는 일반적인 스크립트 실행에서 스크립트 위치를 기준으로 상위 폴더를 탐색합니다. `load_dotenv(".env")`처럼 상대 경로를 명시하면 현재 작업 폴더 기준입니다. 두 동작을 같은 것으로 설명하지 않도록 주의하세요. 자세한 탐색 동작은 [python-dotenv 공식 안내](https://github.com/theskumar/python-dotenv)를 참고하세요.

## 4. 명령줄 입력 분석: argparse

```python
parser = argparse.ArgumentParser(description="실습")
parser.add_argument("command", choices=["create", "get", "logout"])
parser.add_argument("value")
args = parser.parse_args()
```

```bash
python day14/main3.py create demo-a
```

`args.command`는 `"create"`, `args.value`는 `"demo-a"`가 됩니다. `choices`는 허용값 목록입니다. 잘못된 값이나 필수 인자 누락은 argparse가 사용법·오류 메시지를 출력하고 보통 종료 코드 2로 처리합니다. 전체 도움말은 `--help`로 확인합니다.

```python
parser.add_argument("text", nargs="?", default="")
```

`nargs="?"`는 해당 위치 인자를 0개 또는 1개 받는다는 뜻입니다. 생략 가능하지만 `chat`일 때 실제 값이 필요한지는 코드가 별도로 검사합니다. 공백이 든 메시지는 터미널에서 `"내 이름은 민수"`처럼 따옴표로 묶어야 한 인자가 됩니다.

## 5. 고유 ID: uuid와 secrets

```python
uuid.uuid4().hex
secrets.token_urlsafe(32)
```

| 함수 | 반환 형태와 용도 |
|---|---|
| `uuid.uuid4()` | 무작위 UUID 객체. 실행별 키 구분 |
| `.hex` | UUID의 하이픈 없는 32자리 16진수 문자열 속성 |
| `secrets.token_urlsafe(32)` | 난수 32바이트를 URL에 쓰기 좋은 문자열로 표현. 세션 ID 생성 |

`.hex`는 함수가 아닌 속성이므로 괄호가 없습니다. `32`바이트와 32글자는 다릅니다. 두 방식 모두 충돌 가능성이 매우 낮지만 수학적으로 중복 불가능한 번호라는 뜻은 아닙니다.

## 6. Redis 연결과 자원 정리

```python
with redis.Redis(
    host="127.0.0.1",
    port=6379,
    decode_responses=True,
    socket_connect_timeout=2,
    socket_timeout=2,
) as client:
    print(client.ping())
```

`decode_responses=True`는 문자열 응답을 `bytes`가 아닌 `str`로 받게 합니다. 숫자나 `None` 같은 모든 응답이 문자열로 바뀌는 것은 아닙니다. `ping()`은 정상 시 Python의 `True`를 반환합니다.

`socket_connect_timeout`은 연결 단계, `socket_timeout`은 소켓 읽기·쓰기 단계의 제한입니다. 프로그램 전체가 반드시 2초 안에 끝난다는 뜻은 아닙니다. 재시도 동작은 설치된 redis 클라이언트 버전·설정에 따라서도 달라질 수 있습니다.

`with ... as client`는 블록 동안 객체를 사용하고 나갈 때 정리하는 문법입니다. 이 소스처럼 자체 연결 풀을 가진 클라이언트는 블록 종료 시 정리됩니다. Redis 서버나 컨테이너는 종료하지 않습니다.

## 7. Redis 기본 명령

| Python 문법 | 역할 | 대표 반환값 |
|---|---|---|
| `client.ping()` | 응답 확인 | `True` |
| `client.set(key, value)` | 문자열 저장·덮어쓰기 | 기본 호출 성공 시 `True` |
| `client.set(key, value, ex=60)` | 저장과 60초 만료 설정 | 기본 호출 성공 시 `True` |
| `client.get(key)` | String 읽기 | 값 또는 `None` |
| `client.ttl(key)` | 남은 초 확인 | 초, `-1`, `-2` |
| `client.expire(key, 60)` | 기존 키에 60초 만료 설정 | 적용 시 `True`, 키 없음 등은 `False` |
| `client.delete(key1, key2)` | 키 삭제 | 삭제한 키 개수 |
| `client.type(key)` | 자료형 확인 | 설정에 따라 `"string"`, `"hash"`, `"list"`, `"none"` 등 |

일반적인 `set()`으로 기존 키를 덮어쓰면 이전 TTL은 유지되지 않습니다. 유효기간이 필요하면 이 코드처럼 `ex`를 함께 지정하세요. 명령 세부 옵션은 [Redis SET 문서](https://redis.io/docs/latest/commands/set/), TTL 반환값은 [Redis TTL 문서](https://redis.io/docs/latest/commands/ttl/)를 참고하세요.

## 8. Hash와 List 명령

```python
client.hset("profile", mapping={"name": "민수", "level": "basic"})
client.hset("profile", "level", "practice")
name = client.hget("profile", "name")
profile = client.hgetall("profile")
```

Hash는 `키 → 필드 → 값`의 두 단계로 접근합니다. `mapping`은 여러 필드를 한 번에 지정합니다. `hget()`은 없는 필드에 `None`, `hgetall()`은 없는 키에 빈 사전 `{}`를 반환합니다.

```python
client.rpush("messages", "질문1", "답변1", "질문2", "답변2")
all_messages = client.lrange("messages", 0, -1)
last_two = client.lrange("messages", -2, -1)
client.ltrim("messages", -6, -1)
count = client.llen("messages")
```

- `rpush(key, 값1, 값2, ...)`: 오른쪽 끝에 순서대로 추가, 추가 후 길이 반환
- `lrange(key, start, stop)`: 범위 조회. **끝 인덱스도 포함**
- `ltrim(key, start, stop)`: 그 범위만 남기고 나머지 제거
- `llen(key)`: 현재 항목 수
- `-1`: 마지막 항목, `-2`: 뒤에서 두 번째

Python의 `items[0:2]`는 인덱스 2를 제외하지만 Redis `lrange(key, 0, 2)`는 2까지 포함합니다. [Redis LRANGE 문서](https://redis.io/docs/latest/commands/lrange/)의 범위 규칙을 참고하세요.

## 9. JSON과 구조 검사

```python
raw = json.dumps({"role": "user", "content": "안녕"}, ensure_ascii=False)
message = json.loads(raw)
```

`dumps`는 Python 데이터를 JSON 문자열로, `loads`는 그 반대로 변환합니다. `ensure_ascii=False`는 한글을 `\u...` 표현 대신 문자로 남깁니다.

```python
isinstance(message, dict)
message.get("role") in ("user", "assistant")
isinstance(message.get("content"), str)
```

`isinstance(값, 자료형)`은 자료형 검사입니다. 사전의 `.get("필드")`는 키가 없을 때 기본적으로 `None`을 돌려줍니다. Redis의 `client.get()`과 이름이 같지만 서로 다른 객체의 메서드입니다.

## 10. SQLite 연결·SQL·조회 결과

```python
with closing(sqlite3.connect("messages.db", timeout=5)) as conn:
    with conn:
        conn.execute(
            "INSERT INTO messages(owner, role, content) VALUES (?, ?, ?)",
            ("demo-a", "user", "안녕"),
        )
```

| 함수·문법 | 의미 |
|---|---|
| `sqlite3.connect(path, timeout=5)` | DB 파일 연결. 없으면 생성 시도. 5초는 DB 잠금 대기 제한 |
| `closing(연결)` | 블록 종료 시 실제 `.close()` 호출 |
| `with conn:` | 현재 연결의 트랜잭션을 정상 시 확정, 예외 시 취소하도록 관리 |
| `conn.execute(SQL, 값튜플)` | SQL 한 문장 실행 |
| `conn.executemany(SQL, 튜플목록)` | 같은 SQL에 여러 행의 값을 적용 |
| `.fetchone()` | 결과 한 행을 튜플로 가져오기. 행이 없으면 `None` |
| `.fetchall()` | 결과 전체를 행 목록으로 가져오기 |

이 코드의 기본 트랜잭션 설정에서 `with conn:`은 묶음 저장을 돕지만 **연결은 닫지 않습니다.** 그래서 바깥에 `closing()`을 씁니다. DDL을 포함한 모든 문장이 항상 함께 rollback된다고 일반화할 수는 없습니다. 여기서 핵심 보장은 `save_turn()`의 질문·답변 INSERT 묶음입니다. [Python sqlite3 공식 문서](https://docs.python.org/3.13/library/sqlite3.html#how-to-use-the-connection-context-manager)에서 연결 관리와 트랜잭션 관리의 차이를 확인할 수 있습니다.

```python
rows = conn.execute(
    "SELECT role, content FROM messages WHERE owner = ? ORDER BY id DESC LIMIT ?",
    (owner, 6),
).fetchall()
```

`?`는 값이 들어갈 자리입니다. 문자열을 직접 이어 SQL을 만들지 않고 값을 별도로 전달합니다. 사용자 입력의 따옴표 처리와 SQL 삽입 공격 방지에 도움이 됩니다.

SQL 문법 해석:

| 구문 | 의미 |
|---|---|
| `CREATE TABLE IF NOT EXISTS messages (...)` | 테이블이 없으면 생성 |
| `INTEGER PRIMARY KEY AUTOINCREMENT` | 정수 식별자 자동 부여, 삭제된 최대 번호 재사용 방지 |
| `TEXT NOT NULL` | 텍스트 열, NULL 금지. 빈 문자열 금지까지 뜻하지는 않음 |
| `CHECK(role IN ('user','assistant'))` | 허용된 역할만 저장 |
| `INSERT INTO ... VALUES (...)` | 새 행 저장 |
| `SELECT role, content FROM messages` | 역할·내용 열 조회 |
| `WHERE owner = ?` | 해당 사용자 행만 선택 |
| `ORDER BY id DESC` | ID가 큰 최신 행부터 정렬 |
| `LIMIT ?` | 최대 조회 개수 제한 |
| `COUNT(*)` | 행 개수 |
| `COALESCE(MAX(id), 0)` | 최대 ID. 행이 없어 NULL이면 0 사용 |

`fetchone()[0]`은 첫 행에서 첫 열 값을 꺼냅니다. 예를 들어 `COUNT(*)` 결과 `(4,)`에서 `4`를 꺼냅니다. `(owner,)`의 쉼표는 항목 하나인 튜플을 만드는 데 필요합니다.

## 11. 목록 변환과 모의 응답

```python
messages = [{"role": role, "content": content} for role, content in reversed(rows)]
```

SQL 행 목록 `[('assistant', '답변'), ('user', '질문')]`을 뒤집어 `[{"role": "user", ...}, {"role": "assistant", ...}]`로 바꿉니다. `for role, content`는 두 값을 각각 변수로 나누는 문법입니다.

```python
for index, message in enumerate(messages, start=1):
    print(index, message["content"])
```

`enumerate()`는 항목과 번호를 함께 제공합니다. `start=1`은 표시 번호를 1부터 시작합니다.

```python
text.startswith("내 이름은 ")
text.removeprefix("내 이름은 ")
```

첫 표현은 그 문구로 시작하는지 확인하고, 둘째는 시작 부분의 문구를 제거한 새 문자열을 반환합니다. `reversed(messages)`로 최근 메시지부터 검색하면 가장 최근에 말한 이름을 먼저 찾을 수 있습니다.

## 12. 예외와 종료

```python
try:
    main()
except ValueError as exc:
    print("입력/설정 오류:", exc)
    raise SystemExit(1)
```

`try`는 실행할 부분, `except`는 해당 오류가 나면 처리할 부분입니다. `raise ValueError("설명")`은 오류를 발생시킵니다. `from None`은 원래 오류가 연쇄로 출력되는 것을 줄입니다.

| 예외 | 이 코드에서의 예 |
|---|---|
| `ValueError` | 포트 형식·JSON 구조·명령 인자 검증 실패 |
| `PermissionError` | 유효한 세션을 확인하지 못함 |
| `redis.exceptions.RedisError` | Redis 관련 오류의 상위 범주 |
| `redis.exceptions.ResponseError` | Hash에 GET 등 Redis가 명령 처리를 거절 |
| `sqlite3.Error` | SQLite 연결·SQL 오류 |

`finally`는 성공·실패에 관계없이 실행되는 정리 코드입니다. `raise SystemExit(1)`은 실패 종료, 정상 종료 코드는 보통 0입니다. `if __name__ == "__main__":`은 다른 코드가 import할 때가 아니라 파일을 직접 실행할 때만 시작 코드를 실행하게 합니다.
