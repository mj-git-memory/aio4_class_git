프로젝트 명 : note-demo
기능 : 
    1. 회원가입     ---> 향후 : sns로그인으로 대처
        이메일 주소
        이름(닉네임)
        비밀번호    ---> 향후 : 암호화. 현재는 목업
    2. 로그인
    3. 로그아웃
    4. 비밀번호 찾기    ---> 향후. 현재는 목업만 제공
    5. 방명록
        본문만 작성하는 구조이고, 목록 볼 때는 본문의 10자 정도만 목록으로 보여준다
        그리고 해당 글을 클릭하면, 전체 내용을 보여준다(펼도 팝업이 아닌 현재 body의 hidden 영역에 보여준다)
        5-1. 페이징으로 조회(한페이지에 기본 10개)
        5-2. 상세 내용 확인
        5-3. 자기글은 삭제 및 수정 가능
        5-4. 댓글 기능
        5-5. 불쾌한 표현을 키워드 매핑 또는 정규식 형태로 찾아서 마스킹 처리하기
            5-5-1. 불쾌한 표현은 인터넷 등 최신 정보를 찾아서 최초 구성하고 관리자가 추가 삭제할 수 있게 구성

    6. 최소 화면과 데이터 관계
        ERD로 표현해주고, 데이터베이스 테이블 구조도 명시해
        화면구성은 간단 명로하게 구성하고
