# 스키마 변경

현재 스키마는 `PRAGMA user_version = 1`입니다. 최초 설치는 `flask --app app init-db`로 수행하며 이미 초기화된 DB에는 영향을 주지 않습니다. 규칙 목록이 비어 있어도 다시 초기 규칙을 넣지 않습니다.

향후 변경은 `002_설명.sql`처럼 순서대로 SQL을 추가하고, 다음 절차를 따릅니다.

1. 앱 쓰기를 일시 중단하고 `backup-db`로 백업합니다.
2. 별도 복원 DB에서 변경 SQL과 데이터 보존을 검증합니다.
3. 현재 user_version을 검사한 뒤 한 트랜잭션으로 SQL과 새 user_version을 적용합니다.
4. 실패하면 롤백하고, 성공하면 앱을 Reload해 확인합니다.

현재는 v1 이후 변경이 없으며 미구현 자동 마이그레이션 명령을 제공한 것으로 설명하지 않습니다. user_version이 1인 DB의 init-db는 데이터 보존을 위해 재실행하지 않으며 실제 구조 손상은 관리자 검사·복원으로 처리합니다.
