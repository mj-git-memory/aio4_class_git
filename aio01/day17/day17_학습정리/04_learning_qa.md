# 04. 이전 학습 질문과 답변

이 채팅의 질문을 주제별로 줄여 정리했습니다. 원문 전체 인용이 아니며, 설치 실패·실행 오류·예외 해결에 관한 질문은 제외했습니다. 파일 역할과 실행법은 현재 저장된 코드 기준으로 통일했습니다.

## Q1. Intel 환경에서 설치했던 패키지는 ARM 환경에 모두 다시 설치해야 하나요?

새 환경은 독립된 도구 상자이므로 새 환경에서 사용할 패키지는 설치해야 합니다. 다만 예전에 설치했던 모든 패키지를 옮길 필요는 없습니다. 수업에서 필요한 것부터 설치하면 됩니다. 패키지 폴더를 통째로 복사하는 대신 새 환경에 맞는 패키지를 설치하세요.

Python `.py` 소스 파일은 그대로 사용할 수 있습니다. 코드가 사용하는 패키지와 파일 경로 등 실행 조건은 새 환경에도 갖춰야 합니다.

## Q2. Intel 환경은 Mac에 맞지 않는 환경인가요? 기존 학습 내용은 남겨도 되나요?

Apple Silicon Mac에서는 ARM64가 기본이지만 Intel용 Python도 호환 실행으로 사용할 수 있습니다. 지금까지 잘 실행한 환경이 잘못됐다는 뜻은 아닙니다. 다만 플랫폼별 패키지 배포 차이와 호환성을 고려하면 앞으로의 수업은 ARM64 환경으로 진행하는 편이 관리하기 좋습니다.

기존 `py313`은 남겨두고, 새 수업은 `py313_arm`으로 진행할 수 있습니다. 기존 코드도 새 환경에 필요한 패키지를 갖추면 재사용할 수 있어요. 환경 이름만으로 실제 아키텍처가 정해지는 것은 아닙니다.

```bash
conda activate py313
conda activate py313_arm
```

위 두 줄은 각각 환경을 선택하는 예시입니다. 마지막으로 활성화한 환경을 사용합니다.

## Q3. 기존 `day17/models` 모델을 다른 코드에서도 사용할 수 있나요?

네. 다운로드한 모델 폴더를 `MODEL_DIR`로 가리키면 됩니다. 다시 다운로드하거나 폴더를 복사할 필요가 없습니다. 현재 코드들은 상대 경로 기준이 다르므로 공통 절대 경로 사용법을 [실행 안내](03_run_guide.md)에 적었습니다.

단, 모델 파일을 공유해도 실행 프로그램마다 메모리에 모델을 올릴 수 있습니다. 디스크의 파일과 실행 중 메모리 자원은 구분해야 합니다.

## Q4. `day17/main1.py`, `backend/backend.py`, `backend/main.py`는 무엇이 다른가요?

현재 기준으로 다음과 같습니다.

| 파일 | 목적 | 모델을 직접 불러오나? |
|---|---|---|
| `main1.py` | 화면과 AI 답변 처리를 한 앱으로 구현 | 예 |
| `backend/backend.py` | AI 기능을 API로 제공 | 예 |
| `backend/main.py` | API에 질문을 보내고 답을 화면에 표시 | 아니요 |

예전 대화 시점에는 `backend/main.py`도 백엔드 코드였지만 이후 화면 코드로 바뀌었습니다. 따라서 “두 파일이 거의 같다”는 과거 설명은 현재 파일에는 적용되지 않습니다.

## Q5. 새 `backend/main.py`는 어떤 순서로 동작하나요?

1. `.env`에서 `BACKEND_URL`을 읽습니다.
2. Streamlit 입력창에서 질문을 받습니다.
3. `requests.post()`로 FastAPI의 `/chat`에 보냅니다.
4. 서버가 모델로 답을 생성합니다.
5. 받은 JSON의 `answer`를 화면에 표시합니다.

화면과 서버를 분리했기 때문에 각각 실행해야 합니다. 반면 `main1.py`는 스스로 모델을 실행하므로 별도 API 서버가 필요 없습니다.

## Q6. 어떤 패키지가 각각 필요한가요?

AI 계산은 `torch`, 모델 사용은 `transformers`, 다운로드는 `huggingface-hub`, 설정 읽기는 `python-dotenv`가 담당합니다. 화면에는 `streamlit`, 화면에서 서버로 질문을 보낼 때는 `requests`, 서버 API에는 `fastapi`, 데이터 검사에는 `pydantic`, API 서버 실행에는 `uvicorn`을 사용합니다.

스트리밍 도구 `TextIteratorStreamer`도 `transformers` 안에 있습니다. 별도의 `TextIteratorStreamer` 패키지를 설치하는 것이 아닙니다. 전체 표와 주요 함수 문법은 [패키지·문법 노트](02_packages_and_syntax.md)를 참고하세요.

## Q7. Streamlit과 백엔드는 어떻게 실행하나요?

현재 터미널이 `day17` 폴더이고 `py313_arm` 환경이 활성화돼 있다고 가정합니다.

독립 앱은 터미널 하나에서 실행합니다.

```bash
python -m streamlit run main1.py
```

분리 앱은 아래 명령을 각각 다른 터미널에서 실행합니다.

```bash
python -m uvicorn backend.backend:app --reload
```

```bash
python -m streamlit run backend/main.py
```

스트리밍·대화 이력 버전의 정확한 쌍과 설정은 [실행 안내](03_run_guide.md)에 정리했습니다.

## Q8. 비전공자는 코드를 어떤 순서로 공부하면 좋나요?

먼저 입력창에서 질문을 받아 화면에 표시하는 부분을 읽고, 다음으로 질문이 토큰을 거쳐 모델에 전달되는 과정을 보세요. 그다음 API로 기능을 분리하고, `main_yield.py`로 `yield`를 실험한 뒤 스트리밍 코드를 읽으면 연결하기 쉽습니다. 마지막으로 세션 상태와 대화 이력 전송을 학습하세요.
