<!-- 오늘 000지역을 여행하려고 하는데, 숙소 정보와 날씨 정보를 이용해서 
최적의 여행 코스를 알려줘

숙소 -> 숙소 관련 DB에서 데이터를 찾아서 LLM 제공(api가 있다면 적극적으로 이용)
날씨 -> 날씨 관련 정보를 찾아서 LLM 제공 (api가 있다면 적극적으로 이용) -->

데이터 분석 대시보드를 만들고 싶어.
대상은 데이터를 잘 볼 줄 모르는 일반인 유저들과 데이터에서 인사이트를 얻고자 하는 회사원들이야
예를 들어 도넛 판매 데이터가 있고, 이 데이터를 기준으로 수요 공급 예측을 하고 싶어. 재고가 수요의 1% 미만으로 남을 발주량을 예측하고 싶어.
시계열, 회귀, 머신러닝 등 어떤 분석법을 사용하면 좋을지 검토해서 알려주고, 
시각화 방식은 어느 방식이 좋을지(사용자들이 쉽게 볼 수 있을지) 시장조사해서 알려줘.

내가 준 프롬프트를 CoT와 langchain의 ReAct를 적용해서 고쳐주고, 
대시보드 개발을 위한 설계도와 프롬프트를 만들어주고, agent를 어떻게 활용할지도 계획해줘.
