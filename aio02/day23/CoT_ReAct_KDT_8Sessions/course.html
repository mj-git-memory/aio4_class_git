풀이 예시로 답의 형식을 가르친다

생각의 사슬(Chain-of-Thought, CoT) 프롬프팅은 질문과 정답 사이에 풀이 단계를 담은 예시를 제시하는 방법이다. Wei 등의 연구에서는 여러 예시를 사용했다. 이 실습은 예시를 하나로 줄이고, 각 식의 수량과 단위가 드러나도록 작성한다. Wei 등, 논문 2절

실습 1 · 예시와 실제 질문을 나눈다

lesson.py 상단의 COT가 지시문이다. 먼저 연필 예시를 읽는다. 첫 번째 식은 남은 수량을, 두 번째 식은 한 명의 몫을 구한다. 예시의 숫자와 답은 재닛의 문제와 다르다.

COT = """예시처럼 계산식과 단위를 사용해 한국어로 풀이하고 마지막 줄에 답을 쓴다.
예시 문제: 연필 10자루 중 4자루를 쓰고 나머지를 두 명에게 똑같이 나눈다.
예시 풀이: 남은 연필은 10 - 4 = 6자루이다. 한 명의 몫은 6 ÷ 2 = 3자루이다.
예시 답: 3자루"""

직접 작성하기. 연필 예시의 세 줄을 다음 상황에 맞춰 바꾼다. 귤 12개 중 2개를 먹고 나머지를 5명에게 나누는 문제다. 한 줄에는 남은 수량, 다음 줄에는 한 명의 몫을 단위와 함께 쓴다. 실제 질문을 담는 question은 그대로 둔다.

def prompt(system, question):
    template = ChatPromptTemplate.from_messages([
        ("system", "{instruction}"), ("human", "{question}")
    ])
    value = template.invoke({"instruction": system, "question": question})
    instruction, problem = value.to_messages()
    return [{"role": "system", "content": instruction.content},
            {"role": "user", "content": problem.content}]

첫 번째 메시지는 풀이 형식을, 두 번째 메시지는 풀 문제를 전달한다. invoke가 두 변수에 문자열을 채운다. to_messages()로 꺼낸 내용을 공급자가 받을 역할과 본문으로 구성하면, chat(prompt(COT, question))이 두 메시지를 한 번에 전달한다. {instruction}에 값을 넣는 방식은 다음 실습의 JSON 중괄호도 본문 그대로 전달한다. LangChain 메시지 문서

응답 읽기. 첫 식의 9는 판매할 알의 수(개), 다음 식의 18은 하루 판매액(달러)이다. 모델이 계산의 일부를 생략했다면 실제 응답에서 어느 수량까지 설명했는지 살펴본다.

도구를 요청하고 계산 결과를 돌려받는다

ReAct는 추론과 행동을 결합한다. 모델이 필요한 행동을 선택하면 외부 환경이 결과를 제공하고, 모델은 이 관찰을 바탕으로 다음 행동을 선택한다. 원 연구는 사고 단계(Thought), 행동(Action), 관찰(Observation)을 포함한 예시를 사용했다. 여기서는 행동을 계산 요청 JSON으로 표현하고, 파이썬이 계산한 정수를 관찰값으로 되돌려 준다. Yao 등, ReAct Prompting

실습 2 · 모델과 프로그램이 주고받을 형식을 작성한다

REACT = """문제를 풀 때 계산 도구를 사용한다. 한 번에 JSON 객체 하나만 출력한다.
계산 요청 예: {"action":"subtract","a":10,"b":4}
사용 가능한 action은 add, subtract, multiply이다. a와 b에는 정수를 쓴다.
직전 계산 결과는 Observation 메시지로 전달된다. 다음 계산에는 그 값을 사용한다.
답을 구하면 {"final":"단위가 있는 한국어 답"} 형식으로 마친다."""

직접 작성하기. 계산 요청 예시를 곱셈으로 바꾼다. 예를 들어 {"action":"multiply","a":3,"b":5}는 정수 두 개를 곱하라는 요청이다. 도구 이름과 필드 이름을 유지한 채, 관찰값을 받은 뒤 언제 최종 답을 쓸지 자신의 문장으로 작성한다.

호출 흐름

main()은 먼저 CoT 응답을 기록한 뒤 react()를 호출한다. chat은 선택한 모드에 따라 로컬 대본 함수 또는 providers.py의 원격 호출 객체다. 계산 요청이 들어오면 calculate가 정수를 반환한다. final 응답을 받으면 반복이 끝나고 결과 파일을 저장한다.

코드에서 13이 다음 입력이 되는 곳

모의 실행의 첫 응답은 16에서 3을 빼라는 요청이다. json.loads(reply)는 응답 문자열을 딕셔너리로 바꾼다. 이때 step["a"]는 정수 16, step["b"]는 정수 3이다.

def react(messages, chat, events):
    for _ in range(5):
        reply = chat(messages)
        events.append(("ReAct · 모델 응답", reply))
        messages.append({"role": "assistant", "content": reply})
        step = json.loads(reply)
        if isinstance(step, dict) and set(step) == {"final"} and isinstance(step["final"], str):
            return
        if not isinstance(step, dict) or set(step) != {"action", "a", "b"}:
            raise ValueError("action, a, b 또는 final 필드를 확인한다.")
        value = calculate(step["action"], step["a"], step["b"])
        observation = f"Observation: {value}"
        events.append(("계산 도구 · 반환값", observation))
        messages.append({"role": "user", "content": observation})
    raise ValueError("다섯 번의 응답 안에 최종 답이 없어 종료했다.")
코드 값과 역할
calculate("subtract", 16, 3) 두 인자가 정수인지 확인하고 뺄셈 결과 13을 반환한다. 덧셈과 곱셈도 같은 함수에서 연산명을 확인해 처리한다.
events.append(...) 학생이 읽을 실행 기록에 결과를 추가한다.
messages.append(...) 모델에 다시 보낼 대화 목록에 Observation: 13을 추가한다. 다음 반복의 chat(messages)가 이 값을 받는다.
return 모델이 문자열 값을 가진 final 객체를 보내면 호출자에게 제어를 돌려준다.

두 목록의 차이. events는 수업 화면에 보여 줄 기록이고, messages는 다음 API 요청의 입력이다. 관찰값을 화면에만 출력하면 모델에 전달되지 않는다. 도구 응답은 이 실습의 텍스트 규약에 따라 사용자 역할 메시지로 보낸다.

README.md에 따라 설치한다. 기본 명령은 python lesson.py이다. 모의 실행에서는 모델 응답에 수업용 대본을 쓰고, 계산 도구는 실제로 실행한다. 직접 작성한 프롬프트가 응답에 미치는 영향은 API 모드에서 관찰한다.

실행을 지원하는 코드

providers.py의 RemoteChat은 선택한 계정 설정을 읽는다. prepare는 세 공급자에 같은 messages와 Bearer 인증 형식을 적용하고, __call__은 요청을 보낸다. extract가 choices[0].message.content에서 본문을 꺼내면 chat(messages)의 반환값이 된다. lesson.py의 demo는 같은 위치에서 대본을 반환한다. save는 각 기록의 줄바꿈을 보존해 HTML 파일에 쓰고 파일 경로를 반환한다.

def replay(reply, question):
    events = []
