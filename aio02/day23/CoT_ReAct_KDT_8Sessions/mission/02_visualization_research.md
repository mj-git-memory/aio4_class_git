# 도넛 대시보드 시각화 시장조사

공식 제품 문서를 기준으로 Power BI, Tableau, Metabase의 시각화 구성을 비교했다. 조사 기준일은 2026년 11월 18일이다. 아래 화면 선택은 제품 기능을 참고한 설계 제안이며, 실제 초보 사용자의 이해도는 사용성 평가로 확인한다.

## 제품별 참고 요소

| 제품 | 확인한 공식 자료 | 도넛 대시보드 적용 제안 |
| --- | --- | --- |
| Power BI | 선 그래프로 시간에 따른 추세와 계절 패턴 표현 | 실제 판매량과 미래 예측을 시간축으로 연결 |
| Tableau | 예측 가능한 상호작용, 논리적 배치, 단순한 화면 강조 | 핵심 수치 → 추세 → 제품별 조치 순서로 배치 |
| Metabase | 숫자·추세·막대·표 등 시각화 유형과 관련 문서 제공 | 숫자 카드로 요약하고 표에서 세부 수량 확인 |

근거: [Power BI 선 그래프](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-line-chart), [Tableau 시각화 지침](https://help.tableau.com/current/blueprint/en-us/bp_visual_best_practices.htm), [Metabase 시각화 개요](https://www.metabase.com/docs/latest/questions/visualizations/visualizing-results).

이 비교는 기능과 표현 방식에 대한 공개 자료 조사다. 시장점유율 순위, 유료 요금제 비교 또는 사용자 선호도 조사로 해석하지 않는다.

## 질문별 차트 선택

| 사용자의 질문 | 선택할 표현 | 쉽게 읽도록 할 장치 |
| --- | --- | --- |
| 내일 몇 개를 준비할까 | 권장 발주량 숫자 카드 | 단위·도착일·마지막 갱신 시각 표시 |
| 앞으로 수요가 늘까 | 실제 판매 실선 + 예측 점선 + 예측 범위 띠 | 예측 시작일 구분, 범위의 의미 한 문장 설명 |
| 어떤 제품이 남을까 | 예상 잔여량 가로 막대 | 수량 내림차순 정렬, 개수와 비율 함께 표기 |
| 어느 요일이 바쁠까 | 요일별 막대 | 월요일부터 일요일 순서, 휴무 별도 표시 |
| 재고와 품절 중 무엇을 감수할까 | 발주 시나리오 비교표 | 발주량·잔여율·수요 충족률·비용 나란히 표시 |

도넛을 판매하더라도 도넛 차트를 기본으로 쓰지 않는다. 제품별 잔여량의 미세한 차이를 비교하는 작업에는 정렬된 막대가 더 적합하다는 설계 판단이다. 원형 차트는 적은 범주의 구성비가 꼭 필요한 경우에만 검토한다.

## 초보자 화면과 업무용 화면

초보자 화면에는 ‘내일 권장 발주 90개’, ‘예상 수요 100개’, ‘예상 잔여율 0.8%’처럼 문장형 카드와 그래프 하나를 우선 배치한다. 이 수치는 화면 설명용 가정이며 하나의 실제 계산 결과가 아니다. 업무용 상세 화면에서 매장·제품·기간별 필터, 오차, 예측 범위, 시나리오와 원본 표를 펼친다.

색만으로 정상·주의를 구분하지 않고 아이콘과 문자를 함께 쓴다. 그래프의 단위와 데이터 기준 시점을 고정하고, 마우스를 올리지 않아도 핵심 값을 읽을 수 있게 한다. 예측 범위는 ‘비슷한 조건에서 수요가 들어올 것으로 예상하는 범위’라고 설명하고 확정값으로 표현하지 않는다.

## 사용성 확인 계획

일반 사용자와 회사원을 각 3명 이상 모집하는 소규모 평가를 제안한다. ‘내일 발주량 찾기’, ‘품절 위험이 높은 제품 찾기’, ‘추천 이유 설명하기’를 수행하게 한다. 첫 화면에서 발주량을 30초 안에 찾는지, 예측 범위를 확정값으로 오해하지 않는지 기록한다. 이는 제안된 평가 기준이며 검증된 사용자 조사 결과는 아니다.
