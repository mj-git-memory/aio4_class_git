# 도넛 수요 예측 대시보드 기획

데이터를 잘 모르는 일반 사용자와 회사원이 도넛 판매 추세를 이해하고 발주량을 결정하도록 돕는다. 먼저 기준 예측과 재고 시뮬레이션을 검증하고, LangChain 에이전트로 질문에 맞는 분석 도구를 호출하도록 설계한다.

## 문서 읽는 순서

1. [분석 방법과 재고 목표](01_analysis.md): 데이터, 예측 방법, 1% 목표와 평가 기준
2. [시각화 시장조사](02_visualization_research.md): 기존 제품 비교와 차트 선택
3. [대시보드 설계도](03_dashboard_design.md): 화면, 데이터 흐름, 입출력
4. [에이전트 활용과 개발 계획](04_agent_plan.md): 도구 계약, 호출 예시, 개발 단계
5. [CoT 적용 프롬프트](prompts/cot_prompt.md): 원래 요청을 분석 가능한 요청으로 정리
6. [ReAct 적용 프롬프트](prompts/react_prompt.md): 의도를 분석하고 도구로 근거 확보

## 적용 범위

원본 `mission.md`의 마지막 도넛 대시보드 요구사항을 대상으로 한다. 여행 사례는 의도 분석과 도구 호출을 설명하는 참고 사례로 본다. 이 폴더는 개발 설계와 프롬프트를 제공하며, 실행 가능한 대시보드나 학습 완료된 예측 모델은 포함하지 않는다.

실제 도넛 판매 데이터가 제공되지 않았으므로 문서의 수치는 설명용 가정이다. 잔여 재고 1% 미만은 보장값이 아니라 품절률과 함께 검증할 목표다. 기존 수업 코드와 데이터는 수정하지 않는다.
