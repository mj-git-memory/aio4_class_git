# 도넛 수요 예측과 발주량 분석

예측 모델은 미래 수요의 범위를 추정하고, 발주 계산기는 그 범위와 운영 조건으로 발주량을 선택한다. LLM은 분석 요청을 해석하고 결과를 설명하며, 수요 수치를 임의로 생성하지 않는다.

## 재고 목표 정의

초기 설계에서는 하루 말 판매 가능한 잔여량을 해당 일의 실제 수요로 나눈 값을 잔여율로 정의한다. 사용자가 말한 재고가 폐기량인지 다음 날 이월량인지 운영 시작 전에 확정한다.

- 가용 수량 A = 당일 사용할 수 있는 기초 재고 + 당일 도착한 입고량
- 잔여량 L = max(A − D, 0), 미충족 수요 U = max(D − A, 0)
- D는 실제 수요다. 수요가 0인 날의 일별 비율은 정의하지 않고 별도 집계한다.
- 기간 잔여율 = ΣL / ΣD. 목표는 0.01 미만이다. 이는 모든 날이 1% 미만이라는 뜻이 아니다.
- 수요 충족률 = 1 − ΣU / ΣD. 초기 검토 기준은 95% 이상으로 가정하고 운영자가 확정한다.

판매량은 품절이 없을 때만 수요의 근사치다. 품절일에는 팔리지 못한 주문 기록 또는 수요 추정이 필요하다. 해당 자료가 없으면 미충족 수요와 실제 수요 기준 잔여율은 추정치로 표시한다.

### 숫자로 이해하기

실제 수요가 1,000개이고 가용 수량이 1,005개였다면 잔여량 5개, 잔여율 0.5%다. 가용 수량이 900개라면 잔여율은 0%지만 수요 충족률은 90%다. 두 번째 결과를 발주 성공으로 판정하면 안 된다.

예측 수요가 100개이고 가용 수량이 101개라면 예측값 기준 잔여율은 정확히 1%로, 엄격한 ‘미만’ 조건을 충족하지 않는다. 실제 수요의 변동 때문에 예측 평균에 1%를 더하는 방식만으로 목표를 보장할 수 없다.

## 필요한 데이터

기본 단위는 날짜 × 매장 × 제품이다. 한국 영업일 기준으로 집계하고, 문을 닫은 날과 매출이 누락된 날을 구분한다.

| 필드 | 의미와 용도 |
| --- | --- |
| date, store_id, product_id | 유일한 일별 관측 키 |
| units_sold | 반품 처리 기준을 통일한 판매 수량 |
| opening_stock, received_units, closing_stock, waste_units | 재고 흐름과 폐기 확인 |
| stockout_flag, stockout_time, unmet_orders | 수요가 판매량보다 큰 날 식별 |
| price, unit_cost, salvage_value | 가격 효과와 과잉 재고 비용 |
| promotion, holiday, open_flag | 판매 변화와 휴무 설명 |
| lead_time_days, pack_size, shelf_life_days, capacity | 발주와 입고 제약 |
| weather_forecast, forecast_issued_at | 발주 시점에 알 수 있었던 날씨 예보만 사용 |

최초 실습은 단일 매장·제품, 일 단위, 당일 입고·당일 소진 가능한 완제품을 가정한다. 원재료 발주는 레시피별 소요량과 생산 능력을 연결하는 별도 단계다.

## 분석법 비교와 선택 기준

| 방법 | 좋은 출발 조건 | 한계 | 초기 역할 |
| --- | --- | --- | --- |
| 전주 같은 요일 판매량 | 주간 반복이 있는 판매 데이터 | 행사와 추세 변화 반영이 약함 | 반드시 비교할 기준선 |
| ETS 또는 SARIMA | 제품별 관측이 충분하고 계절성이 안정적 | 짧은 이력과 급격한 변화에 취약 | 시계열 후보 |
| 선형 또는 규제 회귀 | 요일·가격·행사 관계를 설명하고 싶을 때 | 비선형 관계와 상호작용 표현에 한계 | 설명하기 쉬운 후보 |
| Gradient Boosting 분위수 회귀 | 여러 제품과 충분한 관측, 외부 변수가 있을 때 | 누수 방지, 튜닝, 분위수 보정 필요 | 예측 범위와 비선형 관계 후보 |

시계열은 데이터의 시간 구조이고, 회귀·머신러닝은 모델링 방법이다. 서로 배타적인 선택이 아니다. 예를 들어 과거 판매량을 입력으로 쓰는 회귀도 시계열 예측을 수행한다. 데이터가 적으면 복잡한 모델 대신 기준선을 사용하고 결과에 데이터 부족을 표시한다.

분위수 회귀로 예측 범위를 만드는 방법은 [scikit-learn 공식 예제](https://scikit-learn.org/stable/auto_examples/ensemble/plot_gradient_boosting_quantile.html)를 참고한다. 특정 모델이 우수하다는 결론은 실제 데이터의 검증 결과로 결정한다.

## 검증 방식

과거로 학습하고 이후 구간을 검증하는 이동 시점 검증을 사용한다. 예를 들어 충분한 데이터가 있을 때 최근 4주를 최종 평가용으로 남기고, 그 이전 구간에서 여러 차례 학습 종료일을 이동한다. 실제 발주가 2일 전에 이루어지면 2일 뒤 예측으로 평가한다. 시간 순서 분할의 구현 원리는 [TimeSeriesSplit 문서](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)를 참고한다.

전처리·결측 보정·특징 계산은 각 학습 구간에서 수행한다. 이동평균은 최소 하루 이동한 과거 데이터로 계산하고, 미래의 실제 날씨·최종 판매량을 입력에 넣지 않는다.

- 예측 오차: MAE, WAPE. WAPE의 실제 수요 합이 0이면 계산 불가로 표시한다.
- 예측 범위: 분위수 손실과 실제 포함률. 분위수 역전이나 범위 미보정을 검사한다.
- 운영 성과: 기간 잔여율, 수요 충족률, 품절 발생일 비율, 폐기 비용, 추정 이익.
- 최종 선정: 기준선 대비 오차와 운영 성과를 함께 비교하고 마지막 평가 구간에서 확인한다.

## 발주량 선택

먼저 예측 분포 또는 과거 검증 오차로 만든 수요 시나리오를 생성한다. 후보 발주량마다 포장 단위, 입고 시점, 사용 가능한 기초 재고, 생산 한도, 유통기한을 적용하고 예상 잔여율·수요 충족률·비용을 계산한다.

예상 과잉 비용과 품절 비용의 합을 최소화하되, 예상 잔여율 1% 미만과 수요 충족률 기준을 함께 만족하는 후보를 우선한다. 만족하는 후보가 없으면 ‘동시 달성 불가’와 대안을 표시한다. 발주량은 장기 수요 총량에서 단순 차감하지 않고 입고 이후 사용할 수 있는 재고와 수요를 날짜별로 계산한다.

당일 수요가 확정적으로 1,000개, 사용 가능 재고가 100개, 포장 단위가 10개라면 900개를 입고시켜 가용 수량 1,000개를 맞추는 예시가 가능하다. 실제 운영에서는 수요가 확정적이지 않으므로 이 계산만으로 발주를 확정하지 않는다.
